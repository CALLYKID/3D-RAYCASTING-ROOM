DESCRIPTION 
A 3D raycasting platform made using scratch blocks with enemies
and a health tracker as well as a background and movement 
in the 3d room with the enemies chasing the player.
Also added a mini map to help the player know where they are at at any point of the game!
Drawn using the scratch pen extension
Total of 642 scratch blocks

HOW TO PLAY
 Use the arrow keys to mve and turn and use the WASD to walk at respective directions withou the player rotating
 Try to collect all 10 stars in the game and try not to lose many of your health
